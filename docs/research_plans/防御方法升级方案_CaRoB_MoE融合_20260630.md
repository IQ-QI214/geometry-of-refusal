# 防御方法升级方案 v2：载体路由桥（Carrier-Routed Bridge, CaRoB）

> 版本 v2 · 2026-06-30 · 状态：待决策
> 在 v1（防御方法设计框架方案_横向比较）基础上，按用户要求融入自研 MoE 选层思路 + 训练/微调环节。
> 核心目标：(1) 把"方法缝合"升级为"由单一现象推导出的有机整体"；(2) 纳入实质性训练工作（不再纯推理）。

---

## 一、用户两个诉求与本方案的回应

| 诉求 | 回应 |
|---|---|
| 加入自研 MoE 思路，避免被认为"方法缝合" | MoE 选层 router **不是附加组件**，而是 v1 推荐方案"动态多 locus"缺失的那块拼图——它回答了"多个 locus 到底怎么选"。整条链由同一个现象推导，详见第三节"反缝合论证"。 |

## 二、一句话方法定义

**CaRoB（Carrier-Routed Bridge）**：训练一个以视觉载体为条件的轻量路由器，动态地从"被载体重编码到不同层"的位置读出风险证据，再经一个阈值门控触发的后段低秩桥（LoRA），把该证据导向行为控制点恢复拒绝。

> 注：刻意避开 FineSteer 已占用的 "Mixture-of-Steering-Experts / MoSE" 名称，改用"载体路由（Carrier-Routed）"，机制上也确实不同（我们路由的是"读哪层"，不是"用哪个方向向量"）。

---

## 三、反"缝合"论证（本方案最关键的部分）

简单把 E+D+B+MoE 拼起来确实是缝合。但 CaRoB 的四个部件**全部由同一个核心现象推导出来**，构成一条因果链，缺一不可：

```
核心现象（Phase1 已观测 + 文献≥4篇佐证）：
  风险证据随视觉载体(排版/figstep/真实跨模态)在不同层、不同方向被"重编码"
        │  (cos≈0.259, best-layer 随载体前移)
        ▼
推论1：固定单层/单方向的读取必然在换载体时读错位置
        ▼  ⇒ 必须有一个"按载体动态选层"的机制
部件A【MoE 选层 router】= 这个机制的最自然形式（层即专家，router 按载体给层权重）
        │  router 读出风险分 s(x) 与证据向量
        ▼
推论2：读出的证据必须被"用上"才能改变行为，但常开干预会伤 utility
        ▼  ⇒ 必须有一个"按风险分条件触发"的开关
部件B【阈值门控】= 这个开关（s(x)>τ 才激活干预，良性零扰动）
        ▼
推论3：把证据"导向行为"需要可学习的搬运，固定向量表达力不足
        ▼  ⇒ 需要一个可训练、只作用于决策段的桥
部件C【后段门控 LoRA】= 这个桥（只加在"门控层→最后一层"，小秩）
        ▼
推论4：训练这个 router + 桥需要监督信号与稳定性保证
部件D【训练配方】= teacher 引导选层 + null-space/正则保 utility
```

**一句话**：MoE router 是"动态多 locus"的实现，门控是"条件干预"的实现，LoRA 是"gate 修复"的可训练实现——三者都从"载体重编码"这一个现象逼出来，是有机整体而非拼装。这条叙事本身就是论文的方法论贡献。

## 四、撞车地图与差异化（已 arxiv 核实）

| 相关工作 | arxiv | 它做了什么 | 与 CaRoB 的关键区别 |
|---|---|---|---|
| FineSteer / MoSE | 2604.15488 | 专家=方向向量，固定层，单模态文本，attention 门控 | 我们专家=**层探针**，**动态选层**，**多模态**，载体条件 |
| Expert-Aware Refusal Steering | 2606.04160 | 路由原生 FFN 专家做拒绝（攻击向） | 我们路由的是**探针层**，非原生 FFN，且为防御 |
| MoLA / Curriculum-LoRA | NAACL25 / 2506.11672 | 每层放 LoRA 专家，逐层路由（参数高效，非安全） | 我们"层本身即专家"，且服务安全选层 |
| Jailbound / SALLIE / Safety Geometry Collapse | NeurIPS26 / 2604.06247 / 2605.18104 | 实证"拒绝信号随层重编码"，但用**静态逐层探针** | 我们把它从"被动观察"升级为"**router 主动按载体路由**" |
| SafeSteer（v1头号竞品） | 2605.11716 | 探针读风险→解码 steer + 单一模态对齐向量 | 我们用**多 locus + 载体条件 router** 取代单向量；探针读"可读位置"而非"输出有害性"，更早触发 |

**结论**：CaRoB 的新增轴是唯一且清晰的——**"以视觉载体为条件、把 Transformer 层作为探针专家、动态路由读取被重编码的风险证据"**，检索范围内无先例。

## 五、统一架构（融合后的完整方法）

仍是"选层→门控→搬运"主线，每步升级为可训练版：

### 部件 A｜Carrier-Conditioned 选层 Router（自研核心）
- 输入：当前样本隐藏态 + **载体类型 embedding**（input-conditioned routing，2603.11114 证实路由确实是输入条件的）。
- 结构：2 层小 MLP gating（非线性，2503.03213 证明线性专家样本效率差）。
- 输出（解耦设计，借 DirMoE 2602.09001）：一支选"哪些层"（Gumbel-Sigmoid），一支给"被选层信任权重"（softmax/Dirichlet）。
- 读取：`s(x) = Σ_l p_l · probe_l(h_l(x))`，得风险分与证据向量。
- 变体（沿用 v1 文档）：B1 软混合（先做，稳、出热图）→ B2 Top-1 硬路由（升级）→ B3 载体条件（默认带）。
- **附加诊断价值**：router 输出的"载体×层"权重热图，直接是 H1（sensor 迁移）的可视化证据，进 motivation。

### 部件 B｜阈值门控
- `g(x)=σ(α·(s(x)−τ))`，软门控（A2，训练稳）；推理可二值化为硬开关（A1，师姐原意"加载/卸载"）。
- 良性输入 s(x) 低 → g≈0 → 零扰动，天然控过度拒绝（借 null-space/AlphaSteer 2506.07022 思想）。

### 部件 C｜后段门控 LoRA（搬运桥）
- 位置：只加在 **`[gate_locus, 最后一层]`**——证据充分：拒绝回路在后段（Audio LLM 2604.16659）、拒绝在末层前已线性可解码（2605.28553）、中层 SAH 信号最鲁棒（2606.28153）。建议门控探针读**中层**，LoRA 干预延伸到最后一层。
- 秩：**小秩**（错位随 LoRA rank 单调上升，2602.16931；CADRE 用 ~0.23% 参数即够，2606.23487）。
- 输出乘门控 g(x)：只在风险时生效。

### 部件 D｜监督与标签（桥学什么）
- 主线 **C2 蒸馏标签**：用"纯文本版本会拒答时"的 gate 隐状态作 teacher，让桥把视觉输入的 gate 隐状态拉向它（反事实 teacher，信号干净）。
- 消融 **C3 自监督正则**：max corr(s(x), 安全间隔)，证明"标签可省"。
- Router 监督：用已知最优层标签做 **teacher-guided routing**（TGR-MoE 2604.21330，直接解决稀疏路由梯度阻塞/抖动）。

## 六、Router 训练配方（防坍缩 + 防不稳，全部有依据）

一句话配方：**非线性条件化 gating + Loss-Free 偏置均衡(主) + 小 balancing loss & z-loss(辅) + Gumbel 温度退火(软→硬) + 最优层标签 teacher 引导(早期锚定)**。

| 训练问题 | 手段 | 依据 |
|---|---|---|
| 坍缩到单层（主力） | Loss-Free 动态偏置均衡（无干扰梯度，不与安全目标打架） | 2408.15664 |
| 坍缩（兜底） | 小权重 Switch load-balancing loss `α·N·Σf_i·P_i` | 2101.03961 |
| logits 爆炸/发散 | router z-loss（近零成本） | 2202.08906 |
| 早期锁死单层 | Gumbel-Softmax 温度退火（高τ→低τ），训练软、推理硬 | 1611.01144 |
| 稀疏路由梯度阻塞 | teacher-guided 用最优层标签 KL 监督，早期锚定 | 2604.21330 |
| 选择/权重耦合 | DirMoE 式解耦 + 探索→确定调度 | 2602.09001 |

### LoRA 训练防遗忘/过拒
- EWC + anchor-to-prior（CADRE 2606.23487）；Fisher 加权安全子空间正则（FW-SSR 2605.02914）。
- 防过度拒绝：VCL 方差集中损失，作用中层残差（2603.13318，误拒率降 35+pp）。
- 数据量：数百安全样本即可达近全量效果（ReSA 500 样本 2509.11629）；或无标签中性 VQA（VSFA 2603.08486）。

## 九、本地 CPU 可先做的工程（不依赖 GPU）

1. Router 模块骨架：2 层 MLP gating + 载体 embedding 输入 + 解耦双头（Gumbel-Sigmoid / softmax）+ 软混合前向。
2. 防坍缩损失库：Loss-Free 偏置更新器、Switch balancing loss、z-loss、Gumbel 退火调度器（纯张量逻辑，CPU 可单测）。
3. 门控算子：软/硬门控 + null-space 投影。
4. 桥（LoRA）接口与 C2/C3 损失的纯逻辑部分 + 单元测试。
5. 复用现有 dissociation.py / subspace.py 做 locus 表与探针。

GPU 部分：抽隐藏态、实跑 LoRA 训练、跑评测与竞品对比。
