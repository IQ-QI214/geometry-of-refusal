## 〇、为什么先用 numpy（重要约束）

本地环境：`numpy 2.2.6` + `pytest 9.1.1`，**无 torch**。
因此第一阶段把 CaRoB 的"可单测核心数学"用纯 numpy 实现（路由 gating、防坍缩损失、门控算子、桥损失），torch 只留给后续 GPU 上的模型接线（抽隐藏态、实跑 LoRA 训练）。这样本地就能跑 100% 绿色单测，GPU 阶段只做 numpy→torch 的薄封装。

## 二、模块 1：`gating.py`（最先写，被 router 依赖）

### 函数签名
```python
def softmax(logits: np.ndarray, axis: int = -1, temperature: float = 1.0) -> np.ndarray: ...
def switch_load_balancing_loss(gate_probs: np.ndarray, expert_mask: np.ndarray) -> float:
    """Switch Transformer 负载均衡损失 α·N·Σ f_i·P_i（arXiv:2101.03961）。
    gate_probs: (n, L) 每样本对各层的路由概率；expert_mask: (n, L) one-hot 实际选择。"""
def router_z_loss(logits: np.ndarray) -> float:
    """ST-MoE z-loss = mean((logsumexp(logits))^2)，防 logits 爆炸（arXiv:2202.08906）。"""
@dataclass(frozen=True)
class LossFreeBiasState:
    bias: np.ndarray            # (L,) 加到 logits 上的可更新偏置
def update_loss_free_bias(state, expert_load, target_load, lr=1e-3) -> LossFreeBiasState:
    """Loss-Free 动态偏置均衡：超载层减偏置、欠载层加偏置（arXiv:2408.15664）。
    expert_load:(L,) 当前各层被选频率；target_load:(L,) 期望（通常 1/L）。"""
def gumbel_softmax_sample(logits, temperature, rng, hard=False) -> np.ndarray:
    """Gumbel-Softmax 采样；hard=True 用 straight-through（arXiv:1611.01144）。"""
def anneal_temperature(step, t_start=2.0, t_end=0.5, total_steps=1000) -> float:
    """温度退火：训练软(高τ)→推理硬(低τ)，指数或线性。"""
```

### TDD 测试点（`test_routing_core.py`）
1. `softmax` 每行和为 1；`temperature` 越大分布越均匀（熵单调）。
2. `switch_load_balancing_loss`：完全均衡负载 → 损失达理论最小 `α`；全压一层 → 损失更大（断言后者 > 前者）。
3. `router_z_loss`：放大 logits 10× → 损失增大；零 logits → 接近 0。
4. `update_loss_free_bias`：超载层 bias 下降、欠载层 bias 上升；多步迭代后负载方差单调下降（收敛性）。
5. `gumbel_softmax_sample`：固定 rng 可复现；`hard=True` 输出 one-hot（行和=1 且只有一个 1）；低温分布更尖。
6. `anneal_temperature`：`step=0` 返回 `t_start`，`step=total_steps` 返回 `t_end`，单调下降。

## 三、模块 2：`router.py`（依赖 gating.py）

### 设计
2 层 MLP gating + 载体 embedding 输入；解耦双头（DirMoE 2602.09001）：一支选层、一支给信任权重。numpy 版用固定/可注入权重矩阵（前向 + 打分，不做反传——反传在 GPU torch 版）。

### 函数签名
```python
@dataclass(frozen=True)
class RouterConfig:
    hidden_dim: int
    num_layers: int            # L，可路由的层数
    num_carriers: int          # 载体类型数（typographic/figstep/real/...）
    carrier_embed_dim: int = 8
    mlp_hidden: int = 32
    mode: str = "soft"         # "soft"(B1) | "top1"(B2)

@dataclass(frozen=True)
class RouterParams:             # 显式持有权重，便于单测注入与确定性
    w1: np.ndarray; b1: np.ndarray
    w_layer: np.ndarray; b_layer: np.ndarray      # 选层头
    w_trust: np.ndarray; b_trust: np.ndarray      # 信任权重头
    carrier_embed: np.ndarray                     # (num_carriers, carrier_embed_dim)

@dataclass(frozen=True)
class RoutingOutput:
    layer_probs: np.ndarray     # (n, L) 路由分布
    selected: np.ndarray        # (n, L) soft=概率 / top1=one-hot
    trust: np.ndarray           # (n, L) 信任权重

def route(features: np.ndarray, carrier_ids: np.ndarray,
          params: RouterParams, config: RouterConfig,
          temperature: float = 1.0, rng=None) -> RoutingOutput: ...

def aggregate_risk_score(layer_probs: np.ndarray,
                         per_layer_probe_scores: np.ndarray) -> np.ndarray:
    """s(x)=Σ_l p_l·probe_l(h_l(x))。
    per_layer_probe_scores:(n,L) 各层探针给的风险分；返回 (n,)。"""
```

### TDD 测试点
1. `route` 输出形状正确；`layer_probs` 每行和为 1。
2. `mode="top1"` 时 `selected` 是 one-hot。
3. **载体条件性**（核心卖点）：构造两类 carrier_id，断言不同载体得到不同 `layer_probs`（routing signature 差异，对应 2603.11114）。
4. `aggregate_risk_score`：若概率全压在第 k 层，则 `s(x)` 等于该层探针分（数值精确）。
5. 确定性：相同输入+rng → 完全一致输出。
6. 退化保护：`hidden_dim`/维度不匹配抛 `ValueError`。

## 四、模块 3：`gate.py`

### 函数签名
```python
def soft_gate(risk_score: np.ndarray, tau: float, alpha: float) -> np.ndarray:
    """g(x)=σ(α·(s−τ))，A2 软门控，返回 (n,) ∈(0,1)。"""
def hard_gate(risk_score: np.ndarray, tau: float) -> np.ndarray:
    """s>τ→1 否则 0，A1 推理期硬开关。"""
def nullspace_projection(delta: np.ndarray, benign_basis: np.ndarray) -> np.ndarray:
    """把干预量 delta 投到良性子空间的零空间，保证良性输入零扰动
    （AlphaSteer null-space 思想 2506.07022）。
    delta:(n,d)；benign_basis:(k,d) 良性方向的正交基；返回 (n,d)。"""
def apply_gated_delta(hidden: np.ndarray, delta: np.ndarray,
                      gate: np.ndarray) -> np.ndarray:
    """h' = h + gate[:,None]·delta。门控为 0 时恒等。"""
```

### TDD 测试点
1. `soft_gate`：`s=τ` → 恰好 0.5；`s≫τ` → 趋近 1；`s≪τ` → 趋近 0；`alpha` 越大越陡。
2. `hard_gate`：阈值两侧 0/1 正确，边界 `s==τ` 行为明确（建议 >τ 才触发）。
3. `nullspace_projection`：投影后的 delta 与 `benign_basis` 每个基向量内积 ≈ 0；对已在零空间的 delta 是恒等（幂等）。
4. `apply_gated_delta`：`gate=0` → 输出等于输入（良性零扰动，关键安全性质）；`gate=1` → 等于 `h+delta`。

## 五、模块 4：`bridge_losses.py`

### 函数签名
```python
def lora_delta(h: np.ndarray, A: np.ndarray, B: np.ndarray, scaling: float) -> np.ndarray:
    """低秩桥：delta = scaling·(h @ A @ B)。A:(d,r) B:(r,d)，小秩 r。"""
def distillation_loss_c2(student_gate_hidden: np.ndarray,
                         teacher_gate_hidden: np.ndarray) -> float:
    """C2：把视觉输入在 gate 处的隐状态拉向'纯文本会拒答'的 teacher 隐状态。
    用 MSE 或 1-cos；返回标量。"""
def self_supervised_corr_loss_c3(risk_score: np.ndarray,
                                 safety_margin: np.ndarray) -> float:
    """C3：-corr(s(x), 安全间隔)，鼓励 sensor 读数与 gate 安全间隔正相关，无需标签。"""
def utility_anchor_penalty(delta: np.ndarray, gate: np.ndarray) -> float:
    """良性样本(gate≈0)上若 delta 仍大则惩罚，防过拒/防遗忘的简化代理。"""
```

### TDD 测试点
1. `lora_delta`：秩为 r 时输出秩 ≤ r；`scaling=0` → 全零；形状正确。
2. `distillation_loss_c2`：teacher==student → 损失 0；差异越大损失越大（单调）。
3. `self_supervised_corr_loss_c3`：完全正相关 → 损失达最小（-1）；完全反相关 → 最大（+1）；常数输入安全处理（不 NaN）。
4. `utility_anchor_penalty`：`gate=0` 且 delta 大 → 惩罚大；`gate=0` 且 delta=0 → 0。
