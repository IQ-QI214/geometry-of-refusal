## 0. 你是谁、要做什么（一句话）

你在一台**有 GPU + 本地模型权重 + 离线 MM-SafetyBench 数据**的机器上。
你的任务分两段，**必须按顺序**：

1. **先修数据**：当前配对数据集的"安全对照图"是空白占位图，导致探针在第 0 层就能完美区分，
   这是**假信号**。你要用已有的中性载体渲染器重建数据并**重抽 VLM 隐状态**，再用一个
   自动闸门确认假信号被破除。
2. **再训练路由**：数据干净后，训练 CaRoB 的 carrier-conditioned router + 门控 LoRA 桥。

**为什么做这件事（研究目标）**：我们在验证一个防御方法 **CaRoB（Carrier-Routed Bridge）**。
核心科学主张是：*VLM 的有害性证据会随"视觉载体"（排版图/figstep/真实图）在不同层被重编码，
所以固定单层读取必然失效，需要一个"按载体动态选层"的路由器把证据读出来、再经门控触发的
后段 LoRA 把证据导向行为控制点恢复拒绝。* 要证明这条链成立，第一步就是拿到**能体现"选层有
意义"的真实数据**——这正是第 1 段要解决的。

## 5. 阶段 C：训练路由（闸门通过后才做）

> 仅当 A4 闸门 OK 且 B 测试全过才开始。否则你会训练在假信号上。

训练所需的三类张量需要你**额外写一个抽取脚本**产生（这是下一批 GPU 代码，目前仓库只有接口约定）：
- `per_layer_probe_scores (n, L)`：用 `routing/probe_bank.py` 的探针对各层隐状态打分得到；
- `gate_hidden (n, d)`：门控层（建议中后层）的隐状态；
- `teacher_gate_hidden (n, d)`：**反事实 teacher**——把同一条样本改成"纯文本版本"（去掉图像，
  仅保留会触发拒答的文本）前向，取同一门控层隐状态。C2 蒸馏让视觉输入的 gate 隐状态拉向它。

最小训练循环骨架（按 round-1 矩阵 T2/T3，详见 `mibd_routing_v2_gpu_runbook_v2.md` 第 3 节）：

```python
import torch
from experiments.mibd_routing_v2.routing import torch_modules as tm

cfg    = tm.TorchRouterConfig(hidden_dim=H, num_layers=L, num_carriers=C, mode="soft")
router = tm.CarrierRouter(cfg).cuda()
gate   = tm.ThresholdGate(tau=0.0, alpha=4.0, learn_threshold=True).cuda()
bridge = tm.LowRankBridge(hidden_dim=H, rank=4, alpha=8.0).cuda()
opt = torch.optim.AdamW([*router.parameters(), *gate.parameters(), *bridge.parameters()], lr=1e-3)

bias   = torch.zeros(L).cuda()
target = torch.full((L,), 1.0/L).cuda()
for step, batch in enumerate(loader):
    T   = tm.anneal_temperature(step, 2.0, 0.5, total_steps)
    out = router(batch.feats.cuda(), batch.carrier_ids.cuda(), temperature=T)
    risk = tm.aggregate_risk_score(out["layer_probs"], batch.per_layer_probe_scores.cuda())
    g    = gate(risk)
    student_gate = bridge(batch.gate_hidden.cuda(), g)
    loss = (
        tm.distillation_loss_c2(student_gate, batch.teacher_gate_hidden.cuda())
        + 0.01 * tm.router_z_loss(out["layer_logits"])
        + 0.01 * tm.switch_load_balancing_loss(out["layer_probs"], out["selected"])
        + 0.1  * tm.utility_anchor_penalty(bridge.delta(batch.gate_hidden.cuda()), g)
    )
    opt.zero_grad(); loss.backward(); opt.step()
    load = out["selected"].mean(dim=0).detach()
    bias = tm.update_loss_free_bias(bias, load, target, lr=1e-3)   # Loss-Free，无梯度
```

实验对照（来自主方案 §七）：T1 固定层 LoRA → T2 +软路由 → T3 +C2 蒸馏桥（完整 CaRoB）。
**Go/No-Go**：T3 必须显著优于竞品 SafeSteer / SafeCoDe，否则退回单 locus 版。
