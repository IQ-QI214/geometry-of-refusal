## 背景（v3 审计的三条问题链）

GPU agent 的泄漏感知审计确认：v3 虽去掉了空白占位图，但**跨载体迁移没有下降**，因为仍存在
视觉/源分布混淆——不是有害语义。三条链：

1. 原闸门用同集 AUC（同一批数据既训探针又测），不是有效科学闸门。

3. 隐状态 npz 缺行级元数据，无法做 pair-level 切分。

## GPU 端操作序列（v4）

### 1. 生成 v4 中性池：**载体齐全 + 画布对齐 risk 的 500×500**

```bash
python -m experiments.mibd_routing_v2.run_build_neutral_safe_pool \
  --output-dir data/mibd_routing_v2/benign_safe_images_v4 \
  --per-category 10 \
  --carriers typographic,figstep \
  --image-size 500          # 对齐 MM-SafetyBench risk 图尺寸，消除 336 vs 500 混淆
```

### 2. 重建配对数据集（载体匹配选图现在自动生效）

```bash
python -m experiments.mibd_routing_v2.run_build_phase2a_dataset \
  --mmsafety-dir /inspire/hdd/global_user/wenming-253108090054/czk/MML/dataset/mm-safebench \
  --safe-image-dir data/mibd_routing_v2/benign_safe_images_v4 \
  --output-dir results/mibd_routing_v2/paired_dataset/phase2a_matched_v4 \
  --num-pairs 200 --seed 20260604
```

### 3.〔CPU 闸门①〕数据审计——**必须 clean 才继续**

```bash
python -m experiments.mibd_routing_v2.eval.run_data_audit \
  --dataset results/mibd_routing_v2/paired_dataset/phase2a_matched_v4/paired_dataset.jsonl \
  --out results/mibd_routing_v2/offline_oracle/v4_data_audit.json
echo "exit=$?"   # 0=CLEAN 继续；1=CONFOUNDED 停下修
```
期望：`carrier_match ≈ 1.0`、safe/risk 图尺寸一致（都 500×500）、像素 std 比值 < 1.5。

### 4. 双 GPU 重抽隐状态（现在会自动写行级元数据）

```bash
conda run -n qwen3-vl python -m experiments.mibd_routing_v2.run_phase2b_extract_probe \
  --model qwen3_vl_8b \
  --dataset results/mibd_routing_v2/paired_dataset/phase2a_matched_v4/paired_dataset.jsonl \
  --output-dir results/mibd_routing_v2/sensor_probe/qwen3_vl_8b_v4 \
  --device cuda:0 --layers 0,4,8,12,16,20,24,28,32,35 --positions=-1

conda run -n rdo python -m experiments.mibd_routing_v2.run_phase2b_extract_probe \
  --model internvl3_8b \
  --dataset results/mibd_routing_v2/paired_dataset/phase2a_matched_v4/paired_dataset.jsonl \
  --output-dir results/mibd_routing_v2/sensor_probe/internvl3_8b_v4 \
  --device cuda:1 --layers 0,4,8,12,16,20,24,27 --positions=-1
```
新 npz 现在含 `row_metadata_json`（每行 sample_id/paired_id/row_index），支持 pair-level 切分。

### 5.〔CPU 闸门②〕泄漏感知探针审计——**这才是训练前的科学闸门**

```bash
python -m experiments.mibd_routing_v2.eval.run_probe_audit \
  --npz results/mibd_routing_v2/sensor_probe/qwen3_vl_8b_v4/hidden_states.npz \
  --out results/mibd_routing_v2/offline_oracle/qwen3_vl_8b_v4_probe_audit.json
```
**Go 条件**（对 v3 的对照）：
- `mean_permutation_heldout_auc ≈ 0.5`（评测器无泄漏，v3 已满足）
- 若"按载体重编码"成立，应看到 **held-out 跨载体迁移 drop 明显 > 0**（v3 是 -0.012，即没有）。
- 若 drop 仍 ≈ 0，说明还有残余混淆或该主张在此数据上不成立——**仍不训练**，回到数据设计。
